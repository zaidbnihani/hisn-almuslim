### Product Requirements Document

| | |
|---|---|

## 1. نظرة عامة على المنتج

تطبيق أندرويد إسلامي شامل بواجهة عربية (RTL) وتصميم داكن فاخر بلمسة ذهبية، يجمع بين خمس وظائف أساسية: الأذكار اليومية، المسبحة الإلكترونية، مواقيت الصلاة مع تنبيه الأذان الصوتي، حصن المسلم (أدعية موقفية)، ومحوّل التاريخ الهجري/الميلادي. يعمل التطبيق بالكامل بدون اتصال إنترنت (offline-first) باستثناء تشغيل صوت الأذان والتحقق من تحديثات سياسة الخصوصية.

### 1.1 المشكلة التي يحلها
تجميع أدوات العبادة اليومية المتفرقة (أذكار، تسبيح، مواقيت صلاة، أدعية مأثورة) في تطبيق واحد بتجربة استخدام سلسة، بدون إعلانات مزعجة، وبتصميم بصري متقن يليق بالمحتوى الديني.

### 1.2 الفئة المستهدفة
مستخدمون ناطقون بالعربية، مسلمون يبحثون عن أداة يومية للأذكار والعبادات، عبر كل الأعمار.

## 2. أهداف المنتج

- توفير محتوى أذكار وأدعية موثّق المصدر (القرآن الكريم، الأحاديث الصحيحة) بسهولة وصول.
- حساب مواقيت صلاة دقيقة حسب الموقع الجغرافي وطريقة الحساب المفضّلة.
- تجربة تسبيح إلكترونية بسيطة وسلسة بديلة عن السبحة التقليدية.
- الحفاظ على تقدم المستخدم اليومي محلياً (بدون حساب أو سحابة).
- الامتثال لمتطلبات الخصوصية القانونية عبر بوابة موافقة إجبارية عند أول استخدام.

## 3. نطاق المنتج — الميزات كما هي مبنية فعلياً

### 3.1 الشاشة الرئيسية / الأذكار (Home Screen)
- عرض 5 فئات أذكار: الصباح، المساء، النوم، الاستيقاظ، بعد الصلاة.
- كل فئة تحتوي قائمة أذكار (نص + مصدر + عدد التكرار المطلوب + ملاحظة فضل الذكر).
- عدّاد تنازلي تفاعلي لكل ذكر: نقرة تُنقص العدد المتبقي، وعند الوصول للصفر يُعاد ضبطه تلقائياً عند نقرة إضافية (دورة تكرار).
- تتبّع اكتمال الفئة يومياً (تاريخ الإنجاز يُخزَّن ويُقارن بتاريخ اليوم).
- شريط تقدم بصري (Completed X / Total).

### 3.2 المسبحة الإلكترونية (Tasbih Screen)
- 8 صيغ تسبيح افتراضية بأهداف عدّ مختلفة (33، 100).
- عدّاد جلسة (Session) وعدّاد إجمالي تراكمي (Total).
- عند بلوغ الهدف، ينتقل تلقائياً للصيغة التالية في السلسلة.
- إمكانية اختيار صيغة تسبيح محددة يدوياً من قائمة.
- زر إعادة ضبط الجلسة الحالية.
- الحالة (index الصيغة، العدّ الحالي، الجلسة، الإجمالي) محفوظة محلياً وتُستعاد عند إعادة فتح التطبيق.

### 3.3 مواقيت الصلاة (Prayer Times Screen)
- حساب 6 أوقات: الفجر، الشروق، الظهر، العصر، المغرب، العشاء — عبر مكتبة `com.batoulapps.adhan`.
- 4 طرق حساب مدعومة: أم القرى، الهيئة المصرية العامة للمساحة، رابطة العالم الإسلامي، الجمعية الإسلامية لأمريكا الشمالية (ISNA).
- 9 مدن مضبوطة مسبقاً (Preset): مكة، المدينة، الرياض، القدس، القاهرة، عمّان، دبي، لندن، نيويورك.
- عدّاد تنازلي حي (Live) للصلاة القادمة بدقة الثانية، مع شريط تقدم دائري.
- عرض التاريخ الهجري والميلادي لليوم الحالي.
- تنبيه أذان تلقائي عند دخول وقت الصلاة: نافذة منبثقة (Overlay) بملء الشاشة + تشغيل صوت أذان فعلي عبر رابط MP3، مع 8 أصوات مؤذنين مختارة (المعيقلي، العفاسي، الحذيفي، المنشاوي، عبد الباسط، أذان الحرم المكي، أذان المسجد النبوي، أذان الأقصى).
- طلب صلاحية موقع (ACCESS_FINE_LOCATION) — **ملاحظة: غير مربوطة فعلياً باستخدام حقيقي، انظر قسم 7**.

### 3.4 حصن المسلم / الأدعية الموقفية (Fortress Screen)
- مكتبة أدعية مصنّفة بـ 8 تصنيفات موضوعية (الهم والغم والشدة، السفر والترحال، الطعام والشراب، المسجد والعبادة، الصحة والرقية، المنزل والمعاش، الخلاء والوضوء، الأحوال والطقس).
- بحث نصي فوري (Real-time filter) بالعنوان والتصنيف والنص.
- فلترة حسب التصنيف عبر شرائح اختيار (Chips/Grid).
- عرض تفصيلي لكل دعاء (نافذة منبثقة) يشمل النص الكامل والمصدر.

### 3.5 محوّل التاريخ (Date Converter Screen)
- تحويل تاريخ ميلادي مُدخَل يدوياً (سنة/شهر/يوم) إلى تاريخه الهجري المقابل.
- خوارزمية حساب فلكي مستقلة (Julian Day) — لا تعتمد على مكتبة خارجية.

### 3.6 الإعدادات (Settings Screen)
- تفعيل/تعطيل صوت الأذان.
- تفعيل/تعطيل الإشعارات (مع طلب صلاحية POST_NOTIFICATIONS على أندرويد 13+).
- اختيار طريقة حساب مواقيت الصلاة.
- اختيار صوت المؤذن + تجربة استماع مباشرة قبل الاختيار.
- تحديد الموقع عبر GPS ("موقعي الحالي") — **ملاحظة: القيمة المُرسلة حالياً وهمية، انظر قسم 7**.
- إعادة ضبط كل بيانات التطبيق (Reset All) مع نافذة تأكيد.

### 3.7 بوابة الموافقة على سياسة الخصوصية (Privacy Consent Gate)
- تُعرض إجبارياً عند أول تشغيل أو عند تحديث نسخة سياسة الخصوصية.
- تتحقق من نسخة السياسة عن بُعد (fetch من رابط خارجي عبر JSON)، مع آلية fallback offline تُبقي المستخدم غير محظور إذا كان قد وافق على نسخة سابقة والشبكة غير متوفرة.
- رفض الموافقة يُغلق التطبيق بالكامل (`finishAffinity()`).
- **ملاحظة: موضع عرضها في الكود الحالي معطوب منطقياً، انظر قسم 7.**

## 4. متطلبات غير وظيفية

| المتطلب | الوصف الحالي في الكود |
|---|---|
| **اللغة والاتجاه** | عربية بالكامل، RTL مفعّل (`android:supportsRtl="true"`) |
| **التخزين** | محلي بالكامل عبر SharedPreferences (`athkar_user_data`) — لا يوجد حساب مستخدم أو مزامنة سحابية |
| **العمل دون اتصال** | كل الميزات تعمل offline باستثناء صوت الأذان (رابط MP3 خارجي) والتحقق من نسخة الخصوصية |
| **الأداء** | عدّاد الصلاة يعمل كل ثانية عبر `viewModelScope` حلقة `while(true) + delay(1000)` |
| **الصلاحيات المطلوبة** | INTERNET, ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION, POST_NOTIFICATIONS, USE_EXACT_ALARM, RECEIVE_BOOT_COMPLETED, VIBRATE, WAKE_LOCK |
| **التصميم البصري** | Dark theme ثابت (لا يوجد Light mode)، لوحة ألوان: خلفية داكنة `#0E1116`، ذهبي `#CEAB62`/`#EFE1C3` |

## 5. البنية التقنية

```
app/src/main/java/com/example/
├── MainActivity.kt              # نقطة الدخول + التنقل + نافذة تنبيه الأذان
├── data/
│   ├── AthkarData.kt            # كل المحتوى الثابت (أذكار، أدعية، مدن، مؤذنين)
│   ├── DhikrModels.kt           # data classes
│   └── PrayerCalculator.kt      # حساب المواقيت + التحويل الهجري
├── ui/
│   ├── MainViewModel.kt         # الحالة المركزية (AthkarUiState) + كل منطق الأعمال
│   ├── components/
│   │   └── IslamicDecorations.kt
│   ├── screens/                 # 7 شاشات Compose
│   └── theme/                   # الألوان والخطوط
```

**نمط معماري:** MVVM بسيط — ViewModel واحد مركزي (`MainViewModel`) يحمل `AthkarUiState` (data class ضخم واحد) كمصدر حقيقة وحيد (Single Source of Truth)، تُقرأ منه كل الشاشات عبر `StateFlow`.

**الاعتماديات الرئيسية:** Jetpack Compose, Navigation Compose, DataStore Preferences (مستوردة لكن الاستخدام الفعلي عبر SharedPreferences مباشرة)، مكتبة `com.batoulapps.adhan` لحساب مواقيت الصلاة.

## 6. تدفقات المستخدم الأساسية (User Flows)

1. **أول تشغيل:** فتح التطبيق → (متوقَّع) بوابة موافقة الخصوصية → الشاشة الرئيسية (أذكار الصباح افتراضياً).
2. **قراءة الأذكار:** اختيار فئة → نقر كل ذكر العدد المطلوب من المرات → الفئة تُعلَّم كمكتملة لليوم.
3. **التسبيح:** فتح شاشة السبحة → نقر متكرر → انتقال تلقائي بين الصيغ عند بلوغ الهدف.
4. **متابعة الصلاة:** فتح شاشة المواقيت → رؤية العد التنازلي → عند الوصول للصفر: نافذة أذان + صوت تلقائي → إيقاف يدوي.
5. **ضبط الموقع:** الإعدادات → تفعيل GPS أو اختيار مدينة من القائمة → إعادة حساب المواقيت تلقائياً.

## 8. خارج النطاق حالياً (Out of Scope / غير موجود بالكود)

- لا يوجد حساب مستخدم أو تسجيل دخول.
- لا توجد مزامنة سحابية بين الأجهزة.
- لا يوجد Light Mode (الوضع الفاتح).
- لا يوجد إشعار مجدوَل فعلي عند إغلاق التطبيق (رغم وجود صلاحيات `RECEIVE_BOOT_COMPLETED` و`USE_EXACT_ALARM` في المانفست، لا يوجد `BroadcastReceiver` أو `AlarmManager` مُنفَّذ بالكود حالياً — التنبيه الحالي يعمل فقط أثناء تشغيل التطبيق في الواجهة الأمامية).
- لا يوجد اختبار وحدة (Unit Tests) أو اختبار واجهة (UI Tests) فعلي رغم وجود اعتماديات الاختبار في Gradle.
- لا يوجد دعم للغات أخرى غير العربية.
